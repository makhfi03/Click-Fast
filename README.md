# Click Fast

Click Fast est un petit jeu de reflexes developpe en HTML, CSS et JavaScript.
Le but est simple : cliquer le plus vite possible sur la cible avant la fin du temps.

## Fonctionnalites

- Saisie du pseudo du joueur
- Choix du mode de jeu :
  - Classique : compter uniquement les clics reussis
  - Precision : compter les clics reussis, les rates et la precision
- Choix de la duree : 10s, 20s ou 30s
- Choix de la difficulte : Facile, Moyenne ou Difficile
- Affichage du score en temps reel
- Page de resultats
- Historique des parties avec `localStorage`
- Sauvegarde des derniers reglages

## Lancer le projet

Ouvrir simplement le fichier `index.html` dans un navigateur.

## Comment jouer

1. Cliquer sur `Jouer`.
2. Entrer un pseudo.
3. Choisir le mode, la duree et la difficulte.
4. Cliquer sur `Lancer`.
5. Cliquer sur la cible le plus rapidement possible.
6. Consulter les resultats a la fin de la partie.

## Technologies utilisees

- HTML
- CSS
- JavaScript
- LocalStorage
